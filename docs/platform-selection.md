# 平台与执行路线

更新：2026-11-13。

目标平台选择微博，消息入口是已接入微信的 AstrBot。
当前先实现文本发帖闭环，评论、回复、点赞随后逐项增加。

| 方案 | 当前定位 | 实测与限制 |
| --- | --- | --- |
| 微博官方 CLI 0.9.8 | 完整接口与参数参照，可保留未来可选后端 | 已授权、目录 75 项；用户考虑额度限制，不作为当前主线 |
| webmcp 微博适配器 0.8.2 | 当前候选执行器 | 登录后动态、详情、评论读取与发帖预演通过；无点赞工具，实际提交未验 |
| 自建 Playwright DOM | 补充实验与缺失能力的实现基础 | DOM 探测已运行；不因页面有动态就判定登录 |

正式接入方式是 Python 插件调用 Node 适配器模块，当前没有启动 MCP 服务。
浏览器登录和 CLI OAuth 是两个独立会话。

所有官方接口均保留在 [全量对照](../research/weibo-tool-matrix.md)，
逐项注明浏览器对应、验证情况和差异；工具数量不作为已完成功能数量。

当前决策与下一步以 [实施路线](../research/implementation.md) 和
[插件设计](plugin-design.md) 为准，不再要求先购买或开通 CLI 服务。
