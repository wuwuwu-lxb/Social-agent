# Social-agent

面向大学创新实践的社交媒体智能体项目。计划以 AstrBot 为底座，让智能体在指定主题和账号设定下，完成内容理解、发帖草稿生成、评论回复、点赞决策和执行记录。

浏览器实验已读取真实动态、详情与评论，并完成发帖预演；两个独立实验分支保留早期代码及只读探测插件。正式插件现已完成微信到真实微博的公开文本发帖闭环，并由用户确认验收通过。

历史进展（2026-11-13）：独立插件 v0.1.0 已部署到本机 AstrBot，完成真实后端
加载、模型工具注册、草稿保存和浏览器预演；当时尚未接入发布。历史细节见
[阶段记录](research/progress-2026-11-13.md)。

历史进展（2026-11-17）：v0.1.1 加入先保存草稿再预演和 `/weibo_drafts`；
该版本记录不代表当前能力状态，详见 [当日记录](research/progress-2026-11-17.md)。

页面 AI 声明选择、单次提交及正文读回核验。真实发布链路已由用户通过微信
实际测试并确认验收成功，见 [阶段总结与证据索引](research/phase-summary-2026-11-19.md)。

## 项目目标

第一阶段成功标准已完成：在微信完成一次真实文本发帖。当前已验收链路：

> 微信提出请求 → AstrBot 展示草稿与任务编号 → 用户确认 → 微博发布 → 核对正文 → 微信收到微博链接

第一版聚焦微博、单账号、文本内容。CLI 0.9.8 已安装并完成授权和命令目录探索；考虑额度限制，当前转向浏览器实验。CLI 保留作行为与参数参考，不作为当前开发前置条件。

## 功能范围

| 阶段 | 功能 | 验收方式 |
| --- | --- | --- |
| 最小版本 | 微信工具调用、文本草稿、确认发布、结果记录 | 微信提出请求，确认后得到可打开核对的微博链接；重复确认不重复发布 |
| 下一阶段 | 读取指定内容、生成回复、确认评论 | 对指定测试内容完成一次评论并验证结果 |
| 下一阶段 | 点赞建议、确认点赞、重复操作检查 | 单独实现适配器缺失能力，记录目标、理由与结果 |
| 后续扩展 | 定时任务、历史记忆、简单统计 | 展示执行历史和统计，验证取消与失败处理 |
| 可选探索 | 多平台、图文、多角色对比 | 主线验收完成后再安排 |

真实平台的每项能力必须单独验证；模拟执行与真实执行在汇报中明确区分。

## 技术方案草案

- AstrBot：作为对话与模型调用入口，已找到本机 4.29.4 桌面安装及 Python SDK。
- 平台执行器：webmcp 微博适配器用于网页预演和读取；真实发布由插件内固定 Playwright 流程执行。
- 项目插件：通过 `main.py`、`metadata.yaml` 和 `Star` 类接入底座，已实现任务、草稿、确认与结果记录。
- 平台适配层：按官方 CLI 的 75 项接口规划工具名与参数，逐项记录真实支持范围，不用占位工具冒充实现。
- SQLite：已用于草稿、任务、预演和发布结果；单任务原子认领与重复确认保护已实现。
- 平台执行：真实公开文本发帖已验收；评论、回复、点赞等写入能力仍需逐项开发与确认。

正式结构与开发顺序见 [插件设计](docs/plugin-design.md)，完整范围见
[官方接口与工具对照](research/weibo-tool-matrix.md)。
下一阶段仍以插件为核心，任务顺序与验收条件见 [下一阶段计划](docs/next-stage-plan.md)。
