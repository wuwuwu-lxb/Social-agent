# Social-agent

面向大学创新实践的社交媒体智能体项目。计划以 AstrBot 为底座，让智能体在指定主题和账号设定下，完成内容理解、发帖草稿生成、评论回复、点赞决策和执行记录。

目前进入浏览器接入实验阶段：已建立两个独立实验分支，并编写只读 AstrBot 探测插件。浏览器能打开微博，插件命令已在本机 AstrBot SDK 下运行；账号登录和桌面端完整链路尚待验证。当前优先完成能运行的链路与技术学习。

## 项目目标

先以单账号打通一条实际操作闭环，账号主题与人设后续配置：

> 输入主题或读取指定内容 → 生成行动建议 → 人工确认 → 平台执行 → 查询结果并记录

第一版聚焦微博、单账号、文本内容。CLI 0.9.8 已安装并完成授权和命令目录探索；考虑额度限制，当前转向浏览器实验。CLI 保留作行为与参数参考，不作为当前开发前置条件。

## 功能范围

| 阶段 | 功能 | 验收方式 |
| --- | --- | --- |
| 最小版本 | 账号风格配置、文本草稿、确认发布、操作日志 | 输入主题，生成草稿，确认后得到发布结果或明确错误 |
| 最小版本 | 读取指定内容、生成回复、确认评论 | 对允许互动的测试内容完成一次评论并验证结果 |
| 最小版本 | 点赞建议、确认点赞、重复操作检查 | 记录目标、理由与结果，同一任务重复提交不重复执行 |
| 后续扩展 | 定时任务、历史记忆、简单统计 | 展示执行历史和统计，验证取消与失败处理 |
| 可选探索 | 多平台、图文、多角色对比 | 主线验收完成后再安排 |

真实平台的每项能力必须单独验证；模拟执行与真实执行在汇报中明确区分。

## 技术方案草案

- AstrBot：作为对话与模型调用入口，已找到本机 4.29.4 桌面安装及 Python SDK。
- 平台执行器：比较现成微博适配器与自建 Playwright DOM 执行器。
- 项目插件：通过 `main.py`、`metadata.yaml` 和 `Star` 类接入底座，逐步实现任务、草稿、确认与日志。
- 平台适配层：统一读取、发布、评论、点赞及结果查询，分别接入模拟平台和真实平台。
- SQLite：暂定用于任务、执行结果和配置记录；密钥单独存放。
- 平台执行：先验证浏览器读取、定位与预演，再接入写入确认流程。模型只生成结构化行动建议，由程序检查后执行。

具体加载目录、SDK 调用示意与逐步验收见 [AstrBot 接入说明](research/astrbot-integration.md)。插件不自带社交平台权限，平台执行需要单独验证。
