## 接口资料如何维护

`specs/weibo/official-cli-catalog.json` 保存去除账号状态的完整接口定义；
`browser-mapping.json` 是人工维护的候选映射与证据；
`tool-contract.json` 和本文链接的全量表由脚本生成，尚不代表工具已经注册。

```powershell
.\tools\sync-weibo-catalog.ps1          # 查询定义并更新，未调用任何业务接口
.\tools\sync-weibo-catalog.ps1 -Offline # 仅从已有快照重建
```

## 证据约定

- 文档确认：已读取项目官方文档或维护者仓库说明。
- 源码确认：已查看对应源码中的工具注册或路由；不等于已运行。
- 本机验证：在本机执行并保存版本、输入、输出与结果。
- 账号验证：在真实授权账号下调用并核对平台结果。

当前：CLI 已授权并完成命令目录探索；本机已安装 AstrBot，浏览器实验与 SDK 命令测试已运行。2026-11-13 专用浏览器已确认登录，webmcp 真实动态、详情与评论读取和发帖预演通过；没有执行真实发帖、评论、点赞。

引用优先指向官方文档、维护者仓库和原论文；不以聚合目录、宣传截图和搜索摘要证明功能已可用。记录时注明日期，真正接入时固定依赖版本及提交号。

论文先保存链接和自己的阅读笔记；需要原文时再下载。登录态、密钥和账号原始数据放入被 Git 忽略的 `data/` 或 `secrets/`，不存到资料目录。
